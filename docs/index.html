🌙

하루 · 조용히 모드

하루 = Claude 5시간 창(낮 → 밤). 합성 환경음, 조용히 모드, 자동 업데이트.

선택 기능 · 기본 꺼짐: 게임에서 Claude 부르기

설정 → 회사 탭에서 켜면 사장 책상 전화 패널에서 직원 있는 프로젝트 하나에 한 줄을 보낼 수 있어요. 게임이 내 PC 의 claude.exe 를 한 번 실행해요. 토큰이 쓰여요. 보낼 때마다 확인 카드가 뜨고, 그 폴더 파일을 읽기만 해요 (최대 5턴 · $0.50 · 120초). 명령과 답은 저장하지 않아요.

설치 · 연결 · 제거

연결은 선택이고, 약 1분이면 돼요.

  1. 받기 — 위의 릴리스에서 SkyOffice-버전-windows-x64.zip → 모두 압축 풀기
  2. 켜기 — SkyOffice.exe 두 번 클릭 → 회사 이름 정하기
  3. 연결 (선택) — 사장 책상의 전화기 → [개통하기] → 하늘색 불이 들어오면 끝 claude 명령을 못 찾았어요 → [명령 복사] → Claude Code 를 쓰는 PowerShell 에 붙여 넣고 Enter. 열려 있던 Claude Code 는 껐다 다시 켜세요.
  4. 확인 — Claude Code 에서 아무 일이나 시키면 직원이 움직여요
  5. 제거 — 설정 → 회사 → 맨 아래 폐업 정리 (플러그인 · 저장 · 자동 실행 삭제) → 게임 폴더는 직접 삭제

개통 전에는 관찰 모드로 동작해요. Claude Code 기록 파일의 수정 시각만 봐요.

개인정보 · 안전

게임에는 승인 버튼이 없어요. 허락은 늘 터미널에서 해요.

받는 것신호 종류 · 도구 이름 · 폴더 끝 이름 · 모델 이름 (Codex 훅)
안 받는 것프롬프트 · 명령 · 파일 내용 · 대화 · 오류 문장 · 환경 변수
저장내 PC 안에만 (%USERPROFILE%\.skyoffice · %APPDATA%\SkyOffice)
인터넷안 써요 (게임은 업데이트 확인만)

훅 12개 모두 출력 없음 · 결정 권한 없음. 켤 때마다 설치 파일 4개의 SHA-256 을 게임 안 원본과 비교하고, 다르면 불통 + 신호 처리 중단이에요. 소스와 해시는 README 에 있어요.

직접 개통 / 제거 (PowerShell) 
claude plugin marketplace add "$env:USERPROFILE\.skyoffice\plugin\0.2.0"
claude plugin install skyoffice-bell@skyoffice --scope user

claude plugin uninstall skyoffice-bell@skyoffice
claude plugin marketplace remove skyoffice
